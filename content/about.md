# About Edmonton Go Tech Meetup

**Go, backend & open-source infrastructure.**

[**Go**](https://go.dev) is an open source programming language that enables the production of simple, efficient, and reliable software at scale.

**Edmonton Go Tech Meetup** is a community for Edmonton developers, sysadmins, homelabbers and technology enthusiasts. Go is our go-to language — used extensively for backend services, CLIs, tooling and systems work — and it runs as the common thread through everything we do.

We organize around problems rather than languages. The challenges technologists face — building reliable services, storing and querying data, running and networking systems, keeping things secure and backed up — are more consistent than the languages used to solve them. We take an open-source approach, because open tools and shared knowledge can solve many, if not all, of those problems.

Come to a Go Night, an Open Source Stack Night, a workshop, a hack night, or a homelab show-and-tell. You don't need to know Go — if you're curious about backend, infrastructure or open source, you're welcome.

**No sales pitches. No corporate presentations. Just people building and running things.**
