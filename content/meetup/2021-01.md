## Talks

### Four Go-to Packages

Matthias Stone shared four packages he pulls into most Go projects. Kelsey Hightower's `envconfig` turns environment variables into a tagged struct in a few lines; Uber's `zap` provides "blazing fast, structured, leveled" logging (sugared or not); `testify` adds sugar around testing with `assert` (behaves like `t.Error`), `require` (fails immediately), and helpers for mocks, HTTP, and test suites; and `urfave/negroni` makes it easy to apply middleware to HTTP call stacks, with useful defaults and composable layers. The talk was explicitly a personal, non-comprehensive list, and ended by asking the audience what their go-to packages were.

Key points:
- A personal, non-comprehensive list of frequently used packages.
- `envconfig`: parse env vars into a tagged struct.
- `zap`: fast structured, leveled logging.
- `testify`: `assert`, `require`, mocks, HTTP, and suite helpers.
- `negroni`: simple, composable HTTP middleware.
- Shared to start a discussion about the audience's go-to packages.
