### Go 1.25 Release

Peter Preeper reviewed Go 1.25, released August 12, 2025, which delivered a broad set of improvements without breaking the Go 1 compatibility promise. On Linux, `GOMAXPROCS` now adapts to cgroup CPU limits (useful in Kubernetes), and the experimental "green tea" GC (`GOEXPERIMENT=greenteagc`) targets 10–40% lower GC overhead for small objects. Other runtime wins include a continuous trace flight recorder, a long-standing nil-check fix, DWARF5 debug info by default, and faster slice allocation. Testing gained `testing/synctest` for deterministic concurrency tests, structured logging via `t.Attr`, and safer parallel benchmarks, while `sync.WaitGroup.Go` eased goroutine launches. Rounding it out: experimental JSON v2, `go doc -http`, TLS 1.2 SHA-1 signatures disabled by default, faster RSA keygen and FIPS mode, `net/http`'s new CrossOriginProtection, and Windows async I/O.

Key points:
- GOMAXPROCS now respects cgroup CPU limits on Linux (great for Kubernetes).
- Experimental `greenteagc` cuts GC overhead by roughly 10–40%.
- A continuous trace flight recorder helps debug rare production issues.
- `testing/synctest` makes concurrency tests deterministic; `sync.WaitGroup.Go` simplifies goroutines.
- Experimental JSON v2 is available via `GOEXPERIMENT=jsonv2`.
- DWARF5 debug info by default and faster slice allocation speed builds.
- Crypto/TLS hardening, faster RSA keygen, and `net/http` CrossOriginProtection.
