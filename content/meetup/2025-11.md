## Agenda

### Go for Web Development

Peter Preeper gave an introduction to using Go for web development, aimed at showing how far the standard library and ecosystem can take you. He covered why Go suits web backends — performance, a simple concurrency model, a strong standard library for HTTP/JSON/templates, single-binary deployment, and frameworks like Gin, Echo, Fiber, Chi, and Buffalo. The talk demonstrated a minimal `net/http` server, then moved to REST APIs with built-in JSON encoding, clean routing, and middleware for logging, auth, and rate-limiting, with a Gin route and logger example. It also covered server-rendered HTML with `html/template` for dashboards and admin panels, WebSockets with Gorilla, and deployment as a static binary via Docker, systemd, or serverless.

Key points:
- Go brings performance, concurrency, and a strong stdlib to web backends.
- A basic server is just `net/http` with `HandleFunc` and `ListenAndServe`.
- Frameworks like Gin, Echo, Fiber, Chi, and Buffalo ease routing and middleware.
- `encoding/json` plus routing frameworks make REST APIs straightforward.
- Middleware handles logging, auth, and rate-limiting.
- `html/template` supports server-side rendering for dashboards and admin panels.
- WebSockets are efficient thanks to goroutines (Gorilla WebSocket).
- Build one static binary and deploy via Docker, systemd, or serverless.
