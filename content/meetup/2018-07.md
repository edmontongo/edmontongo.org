### What's new in Hugo

Nathan Youngman gave a quick look at Hugo, the static site generator, and its new asset pipeline, [Hugo Pipes](https://gohugo.io/hugo-pipes/). Hugo Pipes can compile Sass (`*.scss`) and fingerprint assets directly in templates, for example `{{ $styles := resources.Get "sass/all.scss" | toCSS }}` followed by a `<link>` to the resource's permalink. The talk also covered deployment — pushing to GitHub and automating builds with CircleCI 2.0 and `s3deploy` — and some basic design principles for non-designers: contrast, repetition, alignment, and proximity.

Key points:
- Hugo is a static site generator for blogs and marketing sites.
- Hugo Pipes compiles and fingerprints assets from templates.
- Sass support turns `.scss` into CSS via `toCSS`.
- Deploy by pushing to GitHub and building with CircleCI 2.0.
- `s3deploy` publishes the generated site.
- Basic design: contrast, repetition, alignment, proximity.

## Workshop

Build and deploy a tiny website with Hugo.

You will need:

- A **laptop** (or make a friend who has one and pair program).
- An **idea** for a small website that you want to build.
- Some familiarity with HTML, CSS, Markdown, and the command line.
- Willingness to learn, ask questions, and lookup documentation.

Try to come prepared:

- Install Hugo Extended from [gohugo.io](https://gohugo.io/). Use [Homebrew](https://brew.sh/) on macOS: `brew install hugo`
- Signup for an account with [Amazon AWS](https://aws.amazon.com/), [DigitalOcean](https://m.do.co/c/c0c37ebd590f), or [Netlify](https://www.netlify.com/).

Expect to learn:

- Why use [SASS](https://sass-lang.com/): CSS with superpowers
- Hugo themes with Go templates
- Automating deployments with CircleCI 2.0
- Basic design principles for non-designers
