# Meetup Topics — Idea Bank

_Generated 2026-10-04 from Edmonton Go's own talk archive plus scraped talk/proposal titles from Go meetups worldwide._

This is a working list of **topic ideas** for Edmonton Go Tech Meetup programming. Each topic is tagged with a **general area** so you can browse by theme (deployment, web development, data, etc.), and with a **popularity count** = how many times the idea has been presented across the groups we surveyed, plus **when it was last presented** — overall and at Edmonton.

## How this was built

- **Our archive:** `data/presentations.json` — 52 Edmonton meetups / 74 talks (title + date).
- **External groups:** talk & proposal titles scraped from public Go community group websites in the Go Developers Network (London Gophers, Bärner Go, Go Meetup Prague, Zürich, Leipzig, Bristol, Stuttgart, Roma, Rhein-Ruhr, Golang Japan, EUG Go, Utah Go, GoBridge, Gophers Ethiopia, Go TO, Women Who Go Curitiba).
- **Records analysed:** 777 total (74 Edmonton + 703 external); 429 talks/proposals classified, 0 left uncategorised (0%).
- **Topic** = normalised theme; **Area** = the broader bucket it belongs to; **Times presented** = number of matching talks/proposals.

> **Data notes / limitations.** Many meetup sites are JavaScript apps that publish only their most recent events, so the external sample is deeper for 2024–2026. Golang Japan's monthly round-ups contribute many event-level titles (machine-noise entries such as book clubs were filtered out). "Times presented" counts talks/proposals, not unique speakers, and dates are the event date where available. Treat this as a **directional idea map**, not a precise census.
